# Plugabyte

Plugabyte is a next-generation AI consultancy agency website built using **Next.js**, **Three.js** (via React Three Fiber & Drei), and **Framer Motion**.

## Tech Stack
- **Framework**: Next.js (App Router, TypeScript)
- **3D Engine**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animation**: Framer Motion
- **Styles**: CSS Modules (Vanilla CSS)

## Key Features
- 🚀 **Interactive 3D Particle Field**: A responsive, 3D particle sphere in the Hero section reacting to user cursor and scroll position.
- ✨ **Rich Animations**: Smooth entrance, page scroll interactions, and elegant hover animations powered by Framer Motion.
- 🎨 **Glassmorphism Design System**: Futuristic, modern dark theme styling built on customized CSS variables.
- 📱 **Fully Responsive Layout**: Built with custom media queries to provide a seamless mobile and desktop experience.
- 🔍 **SEO Optimized**: Pre-configured title tags, description, and keywords for high-ranking search engine crawling.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deploying on Vercel

This application is ready to deploy directly to Vercel:

1. Push the code to a GitHub repository.
2. Go to Vercel Dashboard.
3. Click "Add New" -> "Project".
4. Select this repository and click "Deploy".
